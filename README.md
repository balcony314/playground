## 📌 简介 | Introduction

这是一个用于存放个人笔记、实验 Demo 和折腾记录的空间。

A personal space for notes, experiment demos, and tinkering notes.

---

## 📁 目录结构 | Structure

| 目录 Folder | 说明 Description |
|---|---|
| `notes/` | 学习笔记 & 踩坑记录（网络 / 内核 / Linux …） |
| `demos/` | 实验性 Demo 代码 |
| `scripts/` | 常用脚本 & 小工具 |

### demos/

| Demo | 说明 |
|---|---|
| `acc/` | C11 实现的 mini MQTT 3.1.1 broker（master/worker 多进程 + epoll） |
| `ai-agent-demo/` | Go 教学级 AI Agent（Plan + ReAct 模式） |
| `APUE/` | 《UNIX 环境高级编程》练习 |
| `automaton/` | 自动机实现 |
| `AVL/` | AVL 树 |
| `B-Tree/` | B 树 |
| `ebpf_demo/` | eBPF 实验 |
| `eval/` | 表达式求值器（Go，含 AST） |
| `gprobe/` | 基于 eBPF uprobe 的 Go 进程动态追踪探针 |
| `lfu/` | LFU 缓存 |
| `msched/` | 无中心、Pull 模式的分布式任务调度系统设计（Go + gRPC） |
| `nft-copilot/` | nftables 防火墙策略 AI 助手（Policy as Code） |
| `oam/` | 基于 OAM 模型的 Kubernetes 应用部署控制器 |
| `operator-demo/` | Kubernetes Operator 示例 |
| `RBT/` | 红黑树 |
| `skiplist/` | 跳表 |
| `snake/` | 贪吃蛇 |
| `wenqu/` | 数据检索 Agent（ClickHouse / Elasticsearch，基于 Eino） |
| `xds/` | 基于 go-control-plane + Nacos 的 xDS 服务网格控制面 |
